# Tools

Tool-specific benchmark configuration and reproduction notes live here.

Each tool folder should record:

- tool version
- install command or binary source
- benchmark command
- rule pack or query suite
- output format
- known configuration limits

Current tool lanes:

- `cognium/`: Cognium / circle-ir benchmark command and static-analysis notes.
- `cognium-ai/`: cognium-ai static, trust, quality, secrets, and LLM-enrichment
  evaluation notes.
- `codeql/`: CodeQL CLI and query suite notes.
- `semgrep/`: Semgrep ruleset and command notes.
