# Datasets

Dataset source, version, acquisition, and normalization notes live here.

Do not treat benchmark scores as reproducible unless the dataset revision is
pinned. Each dataset folder should record:

- upstream source URL
- commit, release, or snapshot date
- local acquisition command or script
- skipped cases and reasons
- licensing or redistribution constraints

Current datasets:

- `cwe-bench-java/`: source notes for CWE-Bench-Java.
- `top-java-github/`: curated tier-1 Java libraries and infrastructure components for security scanning.
- `top-javascript-github/`: GitHub Search API snapshot for the top 10 non-archived JavaScript repositories by stars.
