# Docs

Website-ready documentation and publication process notes live here.

This folder is for content that supports `cognium.dev/benchmark`, GitHub
Discussions, and public benchmark review. Raw data belongs in `results/` and
`raw/`.

Current docs:

- `publishing.md`: benchmark publishing workflow and forum policy.
- `run-new-benchmarks.md`: practical tracks for fresh SAST benchmark runs and publication.
- `upstream-disclosure-policy.md`: policy for converting benchmark findings into upstream project reports.
- `notion-execution-tracking.md`: Notion database and field guide for benchmark execution tracking.
